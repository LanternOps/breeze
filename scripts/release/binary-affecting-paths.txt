# Paths whose change since the last full release forces a FULL release.
#
# Read by check-server-only-eligibility.sh FROM THE BASE RELEASE'S TREE, so a
# candidate cannot weaken it. Gitignore-style, repo-root anchored: `**` matches
# any depth, `*` matches within one path segment, a leading `!` re-includes a
# path, and the last matching rule wins. `#` starts a comment.
#
# The guarantee this list backs: a server-only release never changes any
# code-signed, notarized or binaries-image artifact, and never changes the
# release/verification machinery. Server-emitted scripts, command delivery and
# binary-selection logic are server code; they are listed for required human
# review in agent-facing-paths.txt instead.
