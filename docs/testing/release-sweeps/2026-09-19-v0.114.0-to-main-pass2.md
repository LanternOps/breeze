### Group 2 — Billing + contracts (paper cuts, none blocking)

1. **`/settings/ticketing` → Categories: duplicate/stale page heading.** The panel renders its own `<h1 data-testid="ticket-categories-heading">` reading **"Ticketing"**, directly under the page's own `<h1>` "Ticketing Settings". Left over from when `TicketCategoriesPage` was a standalone page; every other tab panel starts with a scoped `<h2>` ("Ticket Statuses", "Priorities & SLAs", …). Two `h1`s on one page is also an a11y nit.
2. **Work type is invisible on the ticket's own Time & Billing entry list.** `TicketTimeBilling` renders each entry as `Breeze Admin — <description> | <minutes>` with no work type, so the tech who just picked "Onsite Visit" gets no confirmation on the surface they picked it from. The Work Type column exists only on `/timesheet`.
3. **Quick-add / Timer work-type selects do not pre-select the ticket category's default.** Both open on `No work type` even when the ticket's category has a default (here, Remote Support). The server does apply the default on save, so the outcome is right — but the control shows a value that is not what will be stored. Pre-selecting the resolved default (or labelling the blank option "Category default — Remote Support") would make the field honest.
4. **Service principal scopes render as raw scope strings.** The create/edit drawer lists `organizations:read`, `backup-configuration:read`, `contracts:write` … as bare identifiers in a 2-column grid with no grouping, no read/write separation, and no description of what `contracts:write` actually grants (it is the Partner API contract surface only — not lifecycle, not the human route). This is the screen where an MSP decides to hand a machine identity contract-write power.
5. **Timer widget's stop popover has no work-type control.** The work type is chosen at *start* (`timer-work-type`) and cannot be corrected in `timer-stop-popover`, which does offer description and billable. A tech who forgot to set it must go to `/timesheet` and edit the row afterwards.
