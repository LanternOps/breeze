## Sweep log (append as you go)


### Stack note — API dev image ran under emulation

The first boots ran the API dev image as `linux/amd64` under emulation on an arm64 host (`docker-compose.yml` defaults `DOCKER_PLATFORM` to `linux/amd64`). The main thread then blocked for ~15 s right after `Breeze API running`, and every detached startup task timed out on the database context prologue at the same instant: `AI model registry reconcile failed`, `Recording backup storage key history failed`, `Failed to provision built-in monitors`, `Sealing stored settings secrets failed`, `[legacy-alerting-retirement] listing partners failed`. Same result on three boots. With `DOCKER_PLATFORM=linux/arm64` and `pnpm wt-stack up --rebuild` the block drops to ~2 s and all of them succeed. This is a local-stack artifact, not a product regression, but note that these startup tasks run once per boot with no retry: a host that stalls for 15 s at boot skips them until the next restart.
