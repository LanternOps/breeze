**Top findings**
- An additive error `code` on only some branches of an endpoint makes the branches distinguishable. Here #8123 coded the draft 404 but not the service-error 404 next to it. Converting a route to `ERROR_CODES` should cover every branch that shares a message, not only the lines being edited.
- #8043 fixed the producer (ingest stores unknown as null) but not the consumers that read the column as a boolean. A tri-state migration needs a sweep of every reader (`routes/security/helpers.ts`, dashboard counts, risk score, web types), the same lesson as the partner-wide config sweeps.

- #8214 / #8177 need a live-provider check (one AI agent run plus one chat turn) on a stack with a real key.
- #8043 agent half, #8108 and #8061 need a Windows lab agent (installer/service names, final-path file tools, security collection failure).
- #8070 partner-SSO button on `/login/<slug>` was not checked (no partner SSO configured).
