## Top findings

- **Pages read the header org switcher instead of the page's own org.** Org settings Event Logs, mTLS and Remote Access, and the report edit page contacts and live preview, all used the switcher's org, so a page opened for org B showed or saved org A's data. Fixed on each surface; any new org-scoped page should take its org from the URL or record.
- **403 rendered as "Failed to load".** Unassigned Devices, the invoice workspace, partner billing settings and timesheet showed a raw error to a role that simply lacked access. They now show Access denied; other pages likely still do this.
- **Success toasts that never check the outcome.** PAM approve toasted "approved" when the server had recorded a refusal. Mutation handlers must key the toast on the response status, not on the HTTP call finishing.
- **Tile and table disagree on the same number.** Backup readiness (tile vs Low Readiness table threshold, pending verifications counted as failures), portal "protected devices" (three different counts), and the Outstanding invoice card counting drafts. Each figure needs one resolver shared by tile, table and export.
- **Raw codes and internal values shown to users.** Readiness risk codes, topology diagnostic reason codes, rebuild refusal codes, a 60-character truncated job error. Map codes to sentences at the render boundary.
- **Stale seed and stack traps cost time, not code.** A fresh worktree `.env` breaks every API POST until the URL and HTTPS settings are corrected, the dev override enables the workspace extension without pgvector, and rotated refresh tokens log out a headless driver. Recorded in the `pre-release-sweep` skill (Phase 1).
