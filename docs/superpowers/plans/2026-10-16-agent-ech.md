# Agent ECH (Encrypted Client Hello) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An agent whose control-plane hostname is hijacked by an SNI-matching ISP gateway filter reconnects on its own by encrypting the hostname (ECH), while every other agent's connections stay byte-for-byte what they are today.

**Architecture:** A new `agent/internal/ech` package owns a per-host state machine (`plain → ech → cooldown`), a DoH lookup + on-disk cache for the ECH config, and one `DialTLSContext` closure that performs the TLS handshake itself so it can choose plain or ECH per attempt and fall back inside the same dial. The four control-plane transports (heartbeat, WebSocket, watchdog failover, log shipper) and the one-shot CLI clients (`enroll`/`bootstrap`/`support`) are pointed at that closure. The API gains an additive `configUpdate.ech_enabled` kill switch, two optional heartbeat keys, and two counters — no schema migration.

**Tech Stack:** Go 1.26 `crypto/tls` (client ECH since 1.23, server ECH for tests since 1.24), `net/http`, gorilla/websocket v1.5.3 (`NetDialTLSContext`), DoH JSON API; API: Hono + Zod + prom-client.

**Spec:** `docs/superpowers/specs/agent/2026-10-16-agent-ech-design.md` (read it first; this plan deviates from it in three places, listed in Global Constraints).

## Global Constraints

- Go `1.26.9` (`agent/go.mod`); standard library TLS only; no new modules. DoH via JSON (`Accept: application/dns-json`), never a wire-format parser.
- DoH endpoints, in order: `https://cloudflare-dns.com/dns-query`, `https://dns.google/resolve`. Per-resolver timeout 3 s; one-shot total budget 5 s.
- State-machine constants (spec §1, exact): signature dedupe window **30 s**; threshold **2 events within 10 min**; ECH failure limit **3 consecutive**; cooldown **1 h**. Mode is in-memory only; config cache is persisted. A restart starts `plain`.
- `tls.RecordHeaderError` is a **value type** (`errors.As(err, &rhe)` with `var rhe tls.RecordHeaderError`); `*tls.ECHRejectionError` is a pointer. Filter signature = `RecordHeaderError` whose `RecordHeader[:]` starts with `HTTP/`.
- ECH handshakes must use `MinVersion: tls.VersionTLS13` on the cloned config (Go requirement); `mtls.BuildTLSConfig` pins 1.2, so the ECH clone raises it; the **plain** path keeps the base config's MinVersion untouched.
- `http.Transport.DialTLSContext` makes the transport ignore `TLSClientConfig`, `TLSHandshakeTimeout` and its own ALPN; the closure must set `ServerName` (host without port), `NextProtos` as given by the caller, and a 10 s handshake timeout, so the plain path is byte-equal to today. Gorilla's `NetDialTLSContext` likewise ignores `TLSClientConfig`; gorilla passes no `NextProtos`.
- Proxied connections (`HTTPS_PROXY`) bypass `DialTLSContext`; ECH is not applied through an HTTP proxy. Document, do not work around.
- Kill switch: `configUpdate.ech_enabled` (bool) from the heartbeat response → persisted as `ech_server_enabled`; local operator key is `ech`. Absent = true. Off never tears down live connections.
- **Deviation 1 (spec §4):** no device-row columns and no migration. `echActive` / `filterSignatureSeenAt` are accepted as optional top-level heartbeat keys and surfaced as Prometheus counters; the per-device view is the existing `components.control_plane` entry in the strict v1 health observation.
- **Deviation 2 (spec §5):** `support` persists the ECH cache into its own user-workspace data dir (`config.GetDataDir()` already resolves there); nothing special-cased.
- **Deviation 3 (spec Constraints):** there is no custom-CA `tls.Config` in the agent (OS trust store only); "base config" below means the mTLS config or nil.
- Tests: `cd agent && go test -race -count=1 ./internal/ech/...` style per package; CI runs `go test -race ./...`. No network in unit tests: fake DoH with `httptest`, fake filter with a raw TCP listener, real local ECH server via `tls.Config.EncryptedClientHelloKeys`.
- Never log the auth token, the ECH config bytes, or request bodies. Logging via `logging.L("ech")`.

## Review Focus

1. A captive portal that answers 443 with plaintext once, then goes away: must not engage ECH (threshold is 2 *events*), and the host must not be left degraded. → Task 4 test `TestState_SingleSignatureDoesNotEngage`.
2. DoH reachable but the HTTPS record has no `ech=` (self-hosted edge): host in `ech` mode must dial plain with no delay and count toward cooldown, never spin on DoH. → Task 6 test `TestDial_ECHModeNoConfigFallsBackPlainImmediately`.
3. Edge rotates its ECH key: first ECH dial gets `ECHRejectionError` with `RetryConfigList`; must retry once with the new list, persist it, and stay in `ech`. → Task 6 test `TestDial_RejectionWithRetryConfigRetriesOnce`.
4. Kill switch arrives while a host is in `ech` with a live WebSocket: the socket must stay up; the next dial must be plain. → Task 8 test `TestApplyConfigUpdate_ECHEnabledFalseDoesNotForceReconnect`.
5. Agent upgraded before the API: the two new heartbeat keys and `components.control_plane` must be accepted or stripped by an older API without dropping the health observation. → Task 8 test `TestHeartbeatPayload_ControlPlaneComponentIsV1Shape` (asserts only `state`/`reason` keys and a v1-legal state).

**Files:**

**Interfaces:**

- Produces:
  ```go
  type Options struct {
      TCPDial  func(ctx context.Context, network, addr string) (net.Conn, error) // nil → net.Dialer{Timeout:15s,KeepAlive:30s}; Shared() passes netcache.Shared().DialContext
      Resolver *Resolver   // nil → NewResolver(nil)

      LocalEnabled  bool   // config `ech`
      ServerEnabled bool   // config `ech_server_enabled`
      Now      func() time.Time
      HandshakeTimeout time.Duration // 0 → 10s
  }
  type Dialer struct { /* opts; mu sync.Mutex; states map[string]*hostState; oneShot atomic.Bool; serverEnabled atomic.Bool; fetching map[string]bool */ }
  func New(opts Options) *Dialer
  // DialTLS returns a closure for http.Transport.DialTLSContext / websocket.Dialer.NetDialTLSContext.
  // base may be nil; nextProtos may be nil. The closure never mutates base (clones per attempt).
  func (d *Dialer) DialTLS(base *tls.Config, nextProtos []string) func(ctx context.Context, network, addr string) (net.Conn, error)
  func (d *Dialer) SetServerEnabled(enabled bool)
  func (d *Dialer) SetOneShot(enabled bool)      // first signature → sync fetch (5 s budget) → one ECH retry
  type HostStatus struct { Mode Mode; ECHActive bool; FilterSignatureSeenAt time.Time; InCooldown bool }
  func (d *Dialer) Status(host string) HostStatus
  func (d *Dialer) enabled() bool               // LocalEnabled && serverEnabled
  ```
  Dial algorithm (the only body the plan prescribes):
  1. `host, port := net.SplitHostPort(addr)`; `st := d.state(host)`; `mode := st.Mode(now)`; if `!d.enabled()` → `mode = ModePlain`.
  2. **plain attempt**: `conn := TCPDial`; `cfg := clone(base)`; `cfg.ServerName = host`; `cfg.NextProtos = nextProtos`; `tc := tls.Client(conn, cfg)`; `HandshakeContext` under `HandshakeTimeout`. Success → if `mode == ModeECH` then `st.NotePlainSuccess()`; return `tc`. Error → if `IsFilterSignature(err)`: `engaged := st.NoteSignature(now)`; if `d.oneShot` and enabled: fetch config synchronously (ctx with 5 s), `Cache.Put`, go to step 3 once; else return err. Non-signature error → return err.
  3. **ECH attempt** (mode ECH, or one-shot retry): `list, fresh, ok := Cache.Get(host)`; if `!ok` → `d.fetchAsync(host)`; `st.NoteECHFailure(now)`; goto plain attempt (step 2, but never re-enter step 3). If `!fresh` → `d.fetchAsync(host)` (use the stale list now). `conn := TCPDial`; `cfg := clone(base)`; `cfg.ServerName = host`; `cfg.NextProtos = nextProtos`; `cfg.MinVersion = tls.VersionTLS13`; `cfg.EncryptedClientHelloConfigList = list`; handshake. Success → `st.NoteECHSuccess()`; return. `*tls.ECHRejectionError` with `len(RetryConfigList) > 0` and this is the first ECH try → `Cache.Put(host, ECHConfig{RetryConfigList, 5*time.Minute})`, retry step 3 once. Any other error (or second rejection) → `st.NoteECHFailure(now)`; `Cache.Delete(host)` on rejection with empty retry list; goto plain attempt.
  4. Logging: INFO once per mode transition (`host`, `from`, `to`); WARN once per signature streak (latched like `netcache.noteFallbackEngaged`), DEBUG per attempt outcome.
