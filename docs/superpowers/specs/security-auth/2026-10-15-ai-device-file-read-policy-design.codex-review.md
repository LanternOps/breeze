1. **Minor — A dedicated table is appropriate.** [`ai_budgets`]( apps/api/src/db/schema/ai.ts:225) is org-only; partner defaults currently live in [`partners.settings.aiBudgets`](apps/api/src/services/effectiveSettings.ts:323). [`aiModelRegistryPartnerCutover`](apps/api/src/db/schema/aiModelRegistryCutover.ts:9) records initialization, while [`partner_ai_models`](apps/api/src/db/schema/aiModelRegistry.ts:81) stores individual offerings. Neither fits data policy. **Recommendation:** follow [`aiScriptPolicies`](apps/api/src/db/schema/aiScriptPolicies.ts:16), including unique owner indexes. Define NULL as inheritance, explicit enum ordering, and validate against the partner ceiling—not the current effective value, which creates a ratchet ([policy.ts:149](apps/api/src/services/scriptProposals/policy.ts:149)). Show tighten-only provenance per [settings.md:13](docs/agents/settings.md:13).

2. **Major — `executeTool` is a good core gate, not universal enforcement.** It covers [MCP calls](apps/api/src/routes/mcpServer.ts:1717), [SDK core tools](apps/api/src/services/aiAgentSdkTools.ts:773), [agent runs](apps/api/src/services/aiAgents/runLoop.ts:2345), built-in Helper, and [script-builder execution](apps/api/src/services/scriptBuilderTools.ts:168). However, [Helper client-declared tools](apps/api/src/routes/helper/index.ts:388) bypass it and ignore pre/post hooks; [session-aware cloud tools](apps/api/src/services/aiAgentSdkTools.ts:894) also bypass it. Script-builder apply tools only emit editor updates. `canUseTool` can be [shadowed by `allowedTools`](apps/api/src/services/llm/toolCapture/runSurface.ts:4). **Recommendation:** reuse one policy evaluator at every relevant execution boundary; promote action-aware path metadata from the contract test, preserving diagnostic and sandbox exemptions.

3. **Blocker — Session org is not necessarily the data owner.** Session creation can choose [`accessibleOrgIds[0]`](apps/api/src/services/aiAgent.ts:156); general/device-page chats retain [multi-org read authority](apps/api/src/services/streamingSessionManager.ts:733). Agent runs reliably narrow to [`run.orgId`](apps/api/src/services/aiAgents/agentAuthContext.ts:110). **Recommendation:** resolve from each authorized device’s current `orgId`, after [`enforceDeviceArgs`](apps/api/src/services/aiTools.ts:680), retaining its verified rows. Re-read after approval waits; durable release already [re-enters `executeTool`](apps/api/src/jobs/intentReleaseWorker.ts:1440).

4. **Major — Prefixes cannot establish filesystem containment.** [`candidateForms`](apps/api/src/services/devicePathForms.ts:115) already covers `D:\Users`; [UNC paths are refused](apps/api/src/services/aiPathRestriction.ts:75). But `/private/home` remains unmapped if used as a home alias, redirected profiles are unknown, and arbitrary junctions/symlinks explicitly require [endpoint resolution](apps/api/src/services/aiPathRestriction.ts:26). **Recommendation:** retain API preflight, then enforce signed policy against agent-discovered profile roots and opened handles. Existing [agent checks](agent/internal/remote/tools/fileops.go:535) do not protect entire homes.

5. **Blocker — The proposed script scanner misses actual execution content.** [`run_script`](apps/api/src/services/aiToolSchemas.ts:1013) takes script/proposal IDs; content resolves [inside its handler](apps/api/src/services/aiToolsScripts.ts:407). [`execute_command`](apps/api/src/services/aiToolsScripts.ts:679) has no script variant. **Recommendation:** inspect exact pinned content and parameters at script dispatch. Literal scanning still misses constructed/environment-derived paths; enforceable `off` requires denying arbitrary AI-triggered scripts or constraining their filesystem capabilities.

6. **Major — The level names overpromise.** Excluding homes still permits `/srv/customer` and copies restored elsewhere; the [path contract explicitly recognizes restore-then-read](apps/api/src/services/aiTools.pathParams.contract.test.ts:59). Directory listings also [auto-execute today](apps/api/src/services/aiGuardrails.ts:106). **Recommendation:** make `logs_only` an approved-log-source allowlist or rename it; require approval for home listings if `any_with_approval` promises that.

7. **Major — Retention misses separate output stores.** Large outputs become [artifact blobs and previews](apps/api/src/services/artifacts/toolResultCapture.ts:150), readable through [`read_artifact`](apps/api/src/services/aiToolsArtifacts.ts:85). Workspace steps reference separately persisted [script/stdout artifacts](apps/api/src/services/workspace/workspaceService.ts:455); screenshots have [independent files/expiry](apps/api/src/services/screenshotStorage.ts:180). **Recommendation:** apply retention to blobs, previews, screenshots and read eligibility, including existing records when policy tightens. [`aiInvocations`](apps/api/src/db/schema/aiInvocations.ts:20) contains metadata/costs, not tool payloads; preserve its separate ledger lifecycle.

8. **Major — DB scrubbing does not erase model history.** Chat [persists and resumes SDK transcripts](apps/api/src/services/streamingSessionManager.ts:1305); [continuation summaries](apps/api/src/services/aiModels/continuation.ts:229) can repeat output. **Recommendation:** retire/rebuild expired SDK sessions and explicitly define whether derived summaries are covered. Replace actual transcript results with identifier-preserving tombstones rather than removing tool-call/result pairing.

9. **Major — Wrap only after structured consumers.** [Compaction preserves artifact handles](apps/api/src/services/aiToolOutput.ts:1055); [error detection](apps/api/src/services/aiAgentSdkTools.ts:859) and [script-editor application](apps/web/src/stores/scriptAiStore.ts:573) parse JSON. Early wrapping breaks those paths. **Recommendation:** preserve structured results through compaction, error classification and post-use hooks; wrap only final model-facing text. Consolidate with [`RAW_TEXT_FIELDS_BY_TOOL`](apps/api/src/services/aiToolOutput.ts:986), retaining field sanitization and artifact paging metadata.
