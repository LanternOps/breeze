🔧 **Breeze v0.97.2 is out — migration-safety hotfix**

If v0.97.1 is running fine for you, nothing changed — upgrade whenever. This release is specifically for anyone whose API crash-loops on upgrade with `Migration checksum mismatch`.

**Who hit it:** self-hosters who ran 0.97.0 successfully on the bundled (superuser) Postgres and then moved to 0.97.1. v0.97.1 rewrote a few migration files in place, and a database that had already applied the originals refused to boot. Folks who went straight 0.96.0 → 0.97.1, or run managed Postgres, were never affected.

**The fix:** the migration guard now recognizes those rewrites as a known-safe forward-fix and heals the recorded checksum on boot instead of crashing. No re-migration, no manual DB surgery.

**Self-hosting:** standard upgrade — bump `BREEZE_VERSION=0.97.2`, `docker compose pull api web && docker compose up -d`. No new migrations, no new env vars, no behavior changes.
